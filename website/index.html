SQL editing and exploration
Browse schemas, keys, indexes, and definitions. Find dialect templates with /catalog, inspect supported execution plans, and edit rows when primary-key checks establish a safe update path.
MongoDB, native and SQL
Work with native Extended JSON queries and explicit writes, or use read-only SQL. Complete nested fields and operators, and convert supported SELECTs with /mongo. MongoDB support and limits.
AI clients, with your approval
The local MCP integration lets compatible clients inspect schema and query plans, propose SQL edits, and request execution. Applying edits and running SQL require approval in the desktop. MCP setup guide (Português).

Experimental JDBC and ODBC connections are also available. Supply a JDBC driver JAR or install a compatible 64-bit ODBC driver. Database support and limits.

Import, export, and local storage details

Preview CSV before importing

Choose comma, semicolon, Tab, or a custom delimiter and preview up to 20 rows before a local CSV import. Choose a delimiter for CSV exports, too.

Keep track of what you imported

Choose a full query result or a sample. Full loads are subject to local resource budgets; samples retain only the selected rows. A full export includes the rows available in your imported datasets and cannot restore omitted rows.

Local DuckDB datasets persist after restart. Full analytical exports include a companion provenance file. Import coverage and provenance.

Work with S3 data

Browse and query supported S3 objects, then import them locally when you need a full analytical export. S3 CSV imports use automatic delimiter detection; additional formats depend on DuckDB extensions.
