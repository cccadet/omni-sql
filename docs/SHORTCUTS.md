# Keyboard shortcuts

On macOS, use **Cmd** wherever **Ctrl** appears.

## Editor

| Shortcut | Action |
| --- | --- |
| **Ctrl+Enter** | Run the selection or the statement under the cursor (MongoDB native mode: the command under the cursor; with `/mongo`, convert SQL to native JSON) |
| **Ctrl+Shift+Enter** | Run every statement in the tab |
| **Ctrl+Alt+Enter** | Preview the CTE under the cursor |
| **Ctrl+Alt+L** | Format SQL (change it in **Settings → SQL formatting**) |
| **Ctrl+S** | Save the tab to a `.sql` file |
| **Ctrl+Space** | Show completions |
| **Ctrl+F** / **Ctrl+H** | Find / replace |

Other Monaco editor shortcuts (multi-cursor, line moves, comments) work as in
VS Code.

## Workspace

| Shortcut | Action |
| --- | --- |
| **Ctrl+Alt+O** | Open or close the connection switcher |
| **Ctrl+P** | Search database objects (while the sidebar is open) |

## Results grid

| Shortcut | Action |
| --- | --- |
| Arrow keys | Move between cells |
| **Home** / **End** | First / last column |
| **Ctrl+Home** / **Ctrl+End** | First / last row |
| **Enter** or **F2** | Edit the cell (editable results only) |
| **Escape** | Cancel the edit |
