## 0.5.0 (2026-09-26)

### Improvements

- Browse local analytical results in stable pages without limiting the underlying analysis to the preview grid.
- Export CSV and Parquet with an accompanying `.omni.json` file describing workspace datasets, source coverage and ingestion timestamps.
- Preserve the edited SQL when importing additional datasets and warn when workspace sources are sampled or truncated.
- Show S3 table formats and keep empty schemas available in the object browser.

### Fixes

- Read nested DuckDB and S3 results, including STRUCT, LIST, ARRAY, MAP and UNION values.
- Preserve large numbers and timestamp precision during analytical ingestion; reject driver values whose original precision cannot be recovered.
- Bound streamed record size, recover cleanly from failed ingestion and preserve existing exports when publication fails.
- Keep analytical cancellation effective when requested before DuckDB starts executing the query.
- Retain relational source provenance after reopening a local workspace.

### Validation limits

- Real MariaDB and a working modern 64-bit ODBC driver remain pending validation.
- Forced process crashes, low-disk recovery and the complete resource envelope remain tracked in the analytical engine TODO.
