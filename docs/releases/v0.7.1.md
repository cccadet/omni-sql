# omni-sql v0.7.1

- Corrects macOS packaging of the native keyring library, which blocked publication of v0.7.0.
- Includes macOS 15+ DMG installers for Apple Silicon and Intel, with bundled Node.js and Java runtimes. These builds use ad-hoc signing; authorize the first launch in System Settings → Privacy & Security → Open Anyway.
- Windows updates stop Node.js and Java processes from the application's bundled runtime before replacing files, preventing orphaned runtimes from locking node.exe. Other applications' runtimes remain running.
- Includes Windows NSIS and Linux DEB installers, updater metadata, signatures and SHA256SUMS.
