# omni-sql v0.7.0

## Melhorias

- Instaladores macOS `.dmg` para Apple Silicon e Intel, junto dos instaladores Windows e Linux na mesma release.
- Node.js, Java e o gerenciador ODBC acompanham o aplicativo; não é necessário instalar esses runtimes separadamente.
- Atualização automática com artefatos e assinaturas específicos para cada arquitetura macOS.

## Instalação no macOS

- Requer macOS 15 ou superior.
- Use `aarch64.dmg` para Apple Silicon (M1 ou superior) e `x64.dmg` para Intel.
- Abra o `.dmg`, arraste omni-sql para **Aplicativos** e abra o aplicativo instalado.
- Esta versão usa assinatura ad hoc gratuita, sem notarização Apple. Se a primeira abertura for bloqueada por desenvolvedor não identificado, autorize em **Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim**. Nenhuma conta Apple paga é necessária.
- Conexões ODBC exigem um driver específico do banco, instalado separadamente.

## Downloads

- macOS Apple Silicon e Intel: instaladores `.dmg`.
- Windows: instalador `.exe`.
- Linux: pacote `.deb`.
- `SHA256SUMS`: checksums dos arquivos publicados.
