## 0.3.1 (2026-09-23)

### Features

- **Local analysis sources:** send the selected SQL or current statement from the main editor to Analyze locally, review it in an expanded editor, and import it as a dataset. The compact table and query combobox remains available.

### Bug Fixes

- **Theme contrast:** improve the selected dataset, action icons, source selector, and query placeholder in light and dark modes.
- **Local SQL identifiers:** simplify local dataset identifiers and clarify engine status reporting.
