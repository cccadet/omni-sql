# omni-sql v0.19.1

- DuckLake catalogs stored in PostgreSQL can now set a metadata schema. A lake created with `METADATA_SCHEMA` outside the default schema now attaches instead of failing with "Existing DuckLake at metadata catalog does not exist". Leave the field empty to keep using the default schema.
- The S3 object panel now shows possible DuckLake prefixes without a catalog as a one-line summary. View opens a scrollable dialog that groups the prefixes by bucket with their common prefix and links to catalog configuration. Previously, a long list pushed the rest of the panel out of reach.
