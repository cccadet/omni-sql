## 0.2.7 (2026-09-11)

### Improvements

- **autocomplete:** match column names by exact value, prefix, or substring, ranking exact and prefix matches first. Keyword-shaped fragments such as `at` now continue to find columns such as `created_at` in SQL Server and Oracle.
- **connections:** add generic ODBC connections alongside the existing database adapters.
- **identifiers:** generate SQL with the minimum quoting required by each dialect.
- **documentation:** archive historical project plans and improve the MCP SQL edit-review showcase.

### Bug Fixes

- **settings:** repair the language selector layout.
