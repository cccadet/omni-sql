# omni-sql v0.19.2

- Queries on S3 connections no longer fail with "S3 catalog must contain between 1 and 500 sources". This affected buckets whose catalog has more than 500 tables, such as large DuckLake lakes, and queries run before the sidebar had finished discovering the catalog. A query now sends only the tables it references. If the catalog has not loaded yet, the query discovers it first. An empty catalog now reports a clear error that suggests refreshing the catalog or checking the prefix.
- Removed unused code and dependencies from the desktop app. Behavior is unchanged.
