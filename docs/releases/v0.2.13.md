## 0.2.13 (2026-09-17)

### Bug Fixes

- **Windows updater:** run the externally managed MCP launcher from content-addressed copies of Node and its server bundle outside the installation directory. An MCP client left open can no longer lock the bundled `node.exe` during future updates.

If an update from an older version reports that `resources/runtime/node/node.exe` is open for writing, close the MCP client using omni-sql and select **Retry** in the installer.
