# omni-sql v0.19.0

- Run several native MongoDB commands in one editor: separate the Extended JSON commands with `;`, as in SQL. Run executes the selection or the command under the cursor, and Run all executes every command in order. A `;` inside a string or comment does not split a command.
- The MongoDB native editor no longer shows a JSON "End of file expected" warning when commands are separated by `;`; each command is still validated when it runs.
- Running an editor that holds only `;` or whitespace in MongoDB native mode now does nothing instead of reporting an invalid Extended JSON error.
