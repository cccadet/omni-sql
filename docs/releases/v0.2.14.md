## 0.2.14 (2026-09-17)

### Features

- **Table definitions:** show catalog-backed table DDL for PostgreSQL and MySQL. PostgreSQL definitions include constraints, independent indexes, and table and column comments. Other dialects continue to show a clearly labeled partial definition from cached metadata.
- **Background processes:** inspect the managed Node backend and JVM sidecar from the Help menu, refresh their status, stop a running service, or restart the application and its services.

### Bug Fixes

- **Cancel button:** improve the button's text and background contrast in both light and dark themes while a query is running.
