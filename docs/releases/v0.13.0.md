# omni-sql v0.13.0

- Refresh the SQL workspace with a compact connection header, tabs above query actions, and more room for results.
- Keep local DuckDB datasets visible in the sidebar and open them in a separate SQL tab while preserving the current connection tab.
- Add optional development, staging, and production labels to connections.
- Consolidate result tabs, Table/Documents selection, filtering, column controls, and CSV export into a compact results toolbar. Limit the filter width and move Analyze locally beside query actions.
- Improve cell selection, numeric alignment, execution feedback, and accessible read-only guidance across light and dark themes.
