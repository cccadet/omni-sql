# omni-sql v0.15.0

- Replace the sidebar connection list with a header connection switcher featuring search, recent connections, folders, and per-connection actions. Organize folders and move connections in bulk from the new Manage connections dialog, where whole rows can be dragged onto folders.
- Migrate the remaining screens to the new layout. On Windows, a single title bar carries the window controls. The toolbar stays on one row, extra tabs move to an overflow menu, and editor tabs show the connection name.
- Show PK/FK badges, data types, NOT NULL, foreign-key targets, and descriptions in column suggestions. CTE columns are tagged with their CTE name instead of an unknown type.
- Redesign the connection dialog with a database type picker, step navigation, environment selection, a test result banner, and collapsible schemas.
- Improve MCP views with a client picker, approval origin badges, a line diff when reviewing SQL edits, status tiles, activity filters, and the target tab and connection in edit reviews.
- Add vertical settings navigation, a run shortcut hint, a SQL/Mongo JSON toggle, and a row limit label in the toolbar. Split sidebar height equally between database objects and local analysis.
