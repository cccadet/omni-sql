# omni-sql v0.8.0

- Adds contextual autocomplete for native MongoDB Extended JSON: databases, collections, operation names, sampled fields, query operators and common aggregation stages.
- Adds `/mongo` to convert a SQL SELECT into native MongoDB JSON without executing it. Supports selected fields and aliases, comparisons, logical filters, GROUP BY, COUNT/SUM/AVG/MIN/MAX, HAVING, ORDER BY and LIMIT.
- Conversion preserves the original SQL on unsupported syntax or when the editor changes during conversion. Missing fields and nulls receive explicit handling in filters, counts and aggregates.
- Corrects the initial MongoDB query template to specify database and collection separately.
- Includes Windows NSIS, Linux DEB and macOS Apple Silicon/Intel DMG installers. macOS builds use ad-hoc signing; authorize the first launch in System Settings → Privacy & Security → Open Anyway.

See [MongoDB usage and conversion limitations](../MONGODB.md).
