# omni-sql v0.22.1

- Security: the bundled Java runtime is now Eclipse Temurin JRE 21.0.13, the October 2026 OpenJDK update.
- Security: the bundled Java runtime no longer trusts the eMudhra emSign root certificates, following the OpenJDK eMudhra advisory (CVE-2026-91403, CVE-2026-114820). Temurin 21.0.13 still shipped emSign Root CA - G1, so omni-sql removes it from the bundled trust store, and the build fails if any eMudhra root (or COMODO AAA Certificate Services) is still present. JDBC connections over TLS to servers whose certificates chain to these roots are now rejected.
