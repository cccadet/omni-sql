# omni-sql v0.25.0

- The Windows installer now asks for its language (English, Português (Brasil) or 简体中文) and runs in it.
- On first launch, omni-sql opens in the language chosen in the installer. Without one (macOS, Linux, portable copies, silent installs), it follows the system language and falls back to English.
- A language picked in the app's settings always wins, so updates never change it.
