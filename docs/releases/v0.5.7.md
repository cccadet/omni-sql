# omni-sql v0.5.7

## Melhorias

- Conexões MongoDB com driver nativo: filtros e pipelines em Extended JSON, leitura de coleções e operações explícitas de inserção, atualização e exclusão. Atualizações e exclusões exigem confirmação.
- A tag **SQL** ao lado da conexão ativa alterna para consultas SQL via DuckDB. O modo SQL é sempre somente leitura, com bloqueio no executor e no catálogo.
- Cada aba preserva separadamente os textos dos modos nativo e SQL.

## Validação

- MongoDB 8 autenticado integrado ao Docker Compose e aos comandos de integração e validação de release.
- Testes verificam o fluxo HTTP JSON-RPC nativo e SELECT/EXPLAIN via DuckDB, incluindo rejeição de INSERT, DROP e CREATE no catálogo SQL.

## Observações

- O modo SQL exige acesso ao download da extensão comunitária MongoDB na primeira utilização.
- A execução de MongoDB em modo SQL está disponível pelo editor; a execução desse modo pelo MCP permanece indisponível.
