## 0.4.0 (2026-09-24)

### Features

- **S3 and local DuckDB in the main IDE:** browse buckets and supported CSV, Parquet, Delta, and Iceberg tables through Objects, query them in the SQL editor, and use local DuckDB datasets in S3 joins.
- **Cross-database analysis:** from an S3 connection, choose a table or SQL query from another configured database and import a bounded result for a local join. CSV, JSON, and Parquet file imports create a local DuckDB connection.
- **S3 connections:** configure credentials and multiple buckets per connection. S3 table names and columns participate in editor completion.

### Bug Fixes

- Keep Analyze Locally import errors visible and report actionable source-query errors instead of silently closing the flow.
- Recognize quoted `local` relations in S3 joins and avoid metadata and diagnostics requests before a persisted connection has loaded.
- Add bounded ODBC source streaming with unit coverage, plus Docker source-streaming tests for PostgreSQL, MySQL, MariaDB compatibility, SQL Server, Oracle, and H2/JDBC.
