# omni-sql v0.24.2

Security update. No new features.

- Java4Shell (CVE-2026-114938): the JVM sidecar now starts with HotSpot's accelerated Base64 decoder turned off, which removes the vulnerable code path on x86-64 processors with AVX-512. The bundled Java runtime will be replaced by a fixed build once Eclipse Temurin publishes one.
- The bundled Node.js runtime is now 22.23.5.
- The JVM sidecar now uses Calcite 1.42.0 and patched versions of Jackson, Guava, HttpComponents, protobuf, commons-lang3 and org.json.
- Desktop dependencies with security advisories were updated, including DuckDB 1.5.6, Tauri 2.12 and its plugins, and Arrow/Parquet 58.4.
- The MCP server now uses MCP SDK 1.32.2 and Zod 4.
- Other npm dependencies with security advisories were updated, including the Azure identity library used for SQL Server sign-in.
