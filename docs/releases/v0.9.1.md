# omni-sql v0.9.1

- Improves toolbar grouping and spacing while keeping the SQL editor and result grid usable in smaller windows.
- Moves MongoDB query controls into the toolbar after local analysis actions, with an SQL switch and a visible native conversion button.
- Adds keyboard navigation and named cell editors to the results grid.
- Clarifies connection setup, separates SQL and S3 credentials, and improves settings labels and preview layout.
- Improves SQL/S3 object navigation and exposes metadata refresh progress and failure states.
- Removes duplicated connection details from the Run toolbar; connection context remains in Objects and the status bar.

Native smoke checks covered PostgreSQL object navigation, queries, cell updates, CSV export and SQL errors, plus S3 CSV queries, export, listing failures and recovery using local fixtures. Windows scale at 200% and NVDA remain unverified; these changes do not claim full accessibility certification.

MongoDB SQL conversion limitations remain documented in [MongoDB usage](../MONGODB.md).
