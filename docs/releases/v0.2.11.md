## 0.2.11 (2026-09-16)

### Features

- **autocomplete:** suggest foreign key predicates at the start of a JOIN `ON` clause, using the aliases in the query.
- **results:** navigate from foreign key values to the referenced row.
- **editor:** open a searchable SQL command catalog with `/catalog` and insert a command template.

### Bug Fixes

- **updater:** stop bundled runtimes before installing Windows updates.
- **editor:** explain the current statement or selection and recognize pasted Unicode whitespace.
- **sidebar:** align object rows and tighten spacing.
