# omni-sql v0.16.0

- Add a Compact density option in Settings that tightens result grid rows and the sidebar tree.
- Analyze locally now opens the imported data in a new DuckDB tab and keeps the current tab with its original SQL and connection.
- Security updates: bundled Node.js 22.23.4 (October 2026 security release, including the Brotli remote code execution fix CVE-2026-111497 and TLS hostname verification fixes), bundled Temurin JRE 21.0.12.1, rustls/webpki updates that distrust the compromised emSign intermediates, MCP TypeScript SDK 1.32.1 with patched transitive dependencies, and mysql2 3.24.6.
