# omni-sql v0.23.1

- Fix: running a selection that contains several statements separated by `;` now runs each statement in order instead of sending the whole selection as one command. Selecting multiple `UPDATE`s and pressing **Run** works on databases that accept one statement per call, such as Oracle.
