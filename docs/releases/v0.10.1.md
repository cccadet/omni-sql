# omni-sql v0.10.1

Includes the MongoDB native and SQL completion improvements described in [v0.10.0](v0.10.0.md), whose publication was blocked by the SonarCloud quality gate.

- Passes nested field callback arguments explicitly during SQL metadata conversion.
- Simplifies MongoDB lookup suggestions and preserves local SQL suggestions when backend completion fails.

MongoDB field discovery samples up to 100 documents and 16 nesting levels. Refresh connection metadata to discover new fields. CTE completion depends on the JVM sidecar. Full desktop UI-to-Tauri coverage remains unverified.
