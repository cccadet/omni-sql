# omni-sql v0.22.4

- Fix: SQL Server connections can now reach servers that use a self-signed certificate (the SQL Server default). The connection dialog has **Encrypt connection** and **Trust server certificate (self-signed)** options in place of the unused "SSL require" box, and a failed test that is caused by the certificate now says which option to turn on.
