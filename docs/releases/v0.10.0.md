# omni-sql v0.10.0

- Improves native MongoDB completion with context-aware fields and operators for filters, updates and aggregation stages.
- Adds nested document fields, array element fields and foreign collection suggestions inside `$lookup` pipelines.
- Adds DuckDB function suggestions and nested document field completion to MongoDB SQL and `/mongo` queries.
- Enables backend MongoDB SQL completion, including CTE columns resolved by the JVM sidecar, with local suggestions retained when the sidecar is unavailable.

Validation covered 149 targeted tests, including real MongoDB and JVM integration with CTE completion, plus workspace TypeScript checks and affected lint checks.

MongoDB field discovery samples up to 100 documents and 16 nesting levels. Refresh connection metadata to discover new fields. CTE completion depends on the JVM sidecar. Full desktop UI-to-Tauri coverage was not performed for these changes.
