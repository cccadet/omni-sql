# omni-sql v0.18.0

- Preview a CTE's results while editing SQL: a "Preview" lens above each common table expression (or Ctrl+Alt+Enter and the editor context menu at the cursor) runs that CTE together with the CTEs before it and shows the rows in the results grid, without changing the editor text or the query history. The preview uses the usual row limit, cancellation, variables and risk confirmation, and is refused for data-modifying CTEs (INSERT, UPDATE, DELETE or MERGE) and on MongoDB.
- Export connections: Manage connections can save one or more selected connections to an omni-sql JSON file, keeping label, type, endpoint, user, folder, environment, MCP access, SSL and selected schemas. Passwords never leave the keyring.
- Import connections from an omni-sql export or from DBeaver's `data-sources.json`, with a preview to choose which ones to import. Existing connections are flagged, folders are reused or created, and DuckLake catalogs are re-linked to PostgreSQL connections imported in the same batch. DBeaver PostgreSQL, MySQL, MariaDB, SQL Server and Oracle connections are supported; unsupported drivers are listed with the reason.
- DBeaver imports can also read `credentials-config.json` to fill in user names and passwords. The file is decrypted in memory and passwords go straight to the keyring.
- Clicking outside the connection dialog or pressing Escape now asks before discarding a form with unsaved changes.
