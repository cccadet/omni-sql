# omni-sql v0.21.0

- Desktop notifications: while omni-sql is in the background, it now shows a system notification and flashes its taskbar entry (bounces the Dock icon on macOS) when an MCP client asks you to approve a SQL edit or execution, so approvals no longer expire unnoticed. Queries that run for 10 seconds or more also notify you when they finish or fail. Nothing is shown while the window is focused. Turn it off in Settings → General → Desktop notifications.
- On Linux, notifications need a notification service, which GNOME, KDE, Xfce and Cinnamon include; minimal window managers need one such as `dunst` or `mako`. Taskbar flashing depends on the desktop environment and often does nothing on Wayland.
