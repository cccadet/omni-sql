# omni-sql v0.12.0

- Switch between Table and Documents when viewing native MongoDB query results.
- Explore nested objects and arrays with expandable fields, BSON type labels, keyboard navigation, and support for light and dark themes.
- Preserve original MongoDB documents, including absent fields, null values, and exact BSON values, while sharing filtering and pagination with the table view.
- Refresh the product website with local analysis examples, Portuguese content, and browser language selection.

Document view is available for native MongoDB results and is read-only.
