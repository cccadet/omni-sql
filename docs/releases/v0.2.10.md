## 0.2.10 (2026-09-15)

### Features

- **updater:** download and install signed Windows updates directly from Omni SQL.
- **release:** publish the signed NSIS artifact and Tauri `latest.json` manifest with every release.

### Security

- Updates are verified with the public key embedded in the desktop application before installation.
