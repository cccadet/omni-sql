# omni-sql v0.24.0

- MCP approval modes: each connection with MCP access now has an **MCP approval** setting, useful for dev and staging databases:
  - **Always ask** is the default.
  - **Auto-approve SELECT** runs read-only queries without the approval dialog.
  - **Full permission** runs any SQL the connection allows without the dialog, and needs Read and write access.
- Destructive SQL (`DROP`, `TRUNCATE`, `DELETE` or `UPDATE` without `WHERE`) always asks, whatever the mode.
- MCP after updates: installed builds now give MCP clients a stable server path, so a client picks up the new MCP server after an update without copying the configuration again. Reconnect the client to restart it. Configurations copied from earlier versions keep working and start the current server.
