# omni-sql v0.9.0

- Adds MongoDB SQL conversion for a nonrecursive latest-document CTE joined to its source collection with supported equality conditions.
- Pushes supported MongoDB SQL filters to native queries, including filters on collection reads inside linear CTEs before local DuckDB analysis.
- Infers native MongoDB result and metadata types and displays readable BSON values in query results.
- Formats query duration in readable units.
- Adds the reproducible local-analysis demo visual generator and keeps publication metrics out of the public repository.
- Enforces real database integration before release builds.

See [MongoDB usage and conversion limitations](../MONGODB.md). Other joins and CTE shapes remain unsupported by native SQL conversion; local analysis remains subject to resource budgets.

Installers are available for Windows x64, Linux x64 and macOS Apple Silicon/Intel. macOS builds use ad-hoc signing; authorize the first launch in System Settings → Privacy & Security → Open Anyway.
