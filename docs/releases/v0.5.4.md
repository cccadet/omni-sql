# omni-sql v0.5.4

- Windows installers register a silent uninstall command for WinGet and other
  Windows package managers.
- Windows preflight now installs the generated NSIS bundle and verifies silent
  removal through the actual WinGet client.
- Added initial WinGet manifests and Windows checks for installation and upgrades.
  Community catalog publication follows a separate submission and Microsoft review.

Linux and Windows installers are provided with signatures and SHA256 checksums.
