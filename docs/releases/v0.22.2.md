# omni-sql v0.22.2

- Fix: columns in the query results grid can be resized again. Drag the divider at the right edge of a column header to change its width, double-click it to fit the column to its content, or focus it and use the Left/Right arrow keys (hold Shift for bigger steps). Narrowed columns truncate long values with an ellipsis, and resizing never re-sorts the results.
- Docs: the documentation was reorganized and is now published as a documentation site on GitHub Pages.
