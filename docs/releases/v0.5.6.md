# omni-sql v0.5.6

## Melhorias

- O Explain do Oracle agora mostra estimativas de linhas, bytes, custo e tempo, além dos predicados disponíveis no plano.
- O catálogo SQL inclui **Insert row** para todos os dialetos. Digite `/catalog insert` ou busque por “inserir dados” para inserir o exemplo no editor.

## Validação

- Testes de integração verificam as estimativas disponíveis no Explain de PostgreSQL, MySQL, MariaDB, SQL Server e Oracle pelo backend JSON-RPC.
- A suíte de integração agora usa uma instância MariaDB real, separada do MySQL.

## Downloads

- Windows: instalador `.exe`.
- Linux: pacote `.deb`.
- `SHA256SUMS`: checksums dos arquivos publicados.
