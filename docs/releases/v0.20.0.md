# omni-sql v0.20.0

- Windows releases now include a portable ZIP (`omni-sql_0.20.0_x64-portable.zip`) next to the installer. Extract it to any folder and run `omni-sql.exe`; it needs the WebView2 runtime, which Windows 10/11 usually already has. A portable copy opens the GitHub release page for updates instead of running the installer. Its data still lives in your Windows profile and is shared with an installed copy.
- Result column headers now show the column description from the database, when there is one, in the header tooltip, below the data type.
- Updated the MongoDB Node.js driver to 7.8.0, which fixes a high-severity vulnerability that affects driver versions 7.0.0 up to 7.8.0.
