# omni-sql v0.24.1

- S3 catalogs: connections now discover every table in a bucket. Before, discovery stopped after the first 500 objects, so Delta and Iceberg tables later in the bucket (for example under `materialized/`) never showed up.
- Each Delta or Iceberg table now counts once, however many data files it has.
- If a bucket is too large to list completely, Omni SQL now shows a warning suggesting an S3 prefix. Before, it dropped tables without saying so.
