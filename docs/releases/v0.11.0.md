# omni-sql v0.11.0

- Choose a CSV delimiter when importing local files or exporting results: comma, semicolon, Tab, or a custom printable ASCII character.
- Preview up to 20 rows locally before importing a CSV file, and update the preview when changing the delimiter. Preview reads are bounded; large or invalid previews report an error without creating a dataset.
- Apply the selected delimiter consistently to displayed-row exports and full-result exports, while retaining spreadsheet formula protection.
- Add a reproducible MongoDB native and SQL tutorial and clarify database support and roadmap documentation.

Comma remains the default. Delimiter selection applies to local CSV imports; S3 imports retain automatic detection. Full desktop UI-to-Tauri validation was not performed for this change.
