# omni-sql v0.5.3

- PostgreSQL connection errors now include actionable authentication, network and TLS diagnostics.
- Autocomplete supports correlated subqueries.
- DuckLake catalog discovery returns unique, alphabetically sorted candidates.
- Added regression coverage for PostgreSQL streaming and cleanup, lossless analytical data transport, pagination, cancellation, S3/DuckLake imports and Kotlin query editability.
- Development validation uses a lightweight precommit and a reusable coverage checkpoint for TypeScript, Rust and Java/Kotlin.
- Releases require successful CI, including SonarCloud, for the exact tagged commit.

Linux and Windows installers are provided with signatures and SHA256 checksums.
