## 0.4.1 (2026-09-25)

### Improvements

- Add DuckLake catalog discovery for S3 buckets and table prefixes, backed by a saved PostgreSQL connection or a SQLite/DuckDB file.
- Keep local DuckDB datasets available after restart and clarify the scope of temporary analytical data and full-result exports.
- Make S3 buckets optional when saving a connection. Load available buckets, select the ones to use, and see saved selections when reopening the connection.

### Fixes

- Keep the cursor in connection fields when editing and reopening S3 connections.
- Show connection settings in the selected language, including S3 and DuckLake fields.
- Improve analytical data handling for large numeric values and local data engine lifecycle.
