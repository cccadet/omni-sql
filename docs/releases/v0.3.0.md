## 0.3.0 (2026-09-22)

### Features

- **Local analytics:** analyze database results and imported CSV or Parquet files with the embedded Rust and DuckDB engine, using either complete loads or explicit samples.
- **Full-result streaming:** load complete analytical sources from PostgreSQL, Oracle, MySQL, MariaDB, SQL Server, and generic JDBC connections in bounded batches with cancellation and resource cleanup.
- **Dataset workspace:** open local analysis without running a query first, add, rename, and remove datasets, preserve analytical SQL while importing more sources, and export complete CSV or Parquet results.
- **Contextual SQL assistance:** complete local dataset and column names and suggest joins from imported foreign-key metadata.
- **Integrated interface:** use local analysis in the main IDE workspace with a resizable sidebar section, persistent global toolbar, DuckDB identity, and clearer full-result versus displayed-row load choices.

### Bug Fixes

- **Analytical source names:** assign readable relation names immediately and keep them consistent in autocomplete.
- **Layout:** restore dialog padding, prevent bottom clipping, and compact and align the analysis sidebar controls.
- **Query preservation:** keep the current analytical query when adding another dataset.
